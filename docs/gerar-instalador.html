SmartAcesso — Gerar o instalador

Como compilar as três peças e gerar o Setup.exe em qualquer máquina Windows

Documento interno · SmartPonto
Cobre o repositório smartacesso-installer e os três projetos irmãos (núcleo Java, TopData e Desktop Electron).
Atualização automática não faz parte desta etapa.

1. O que o instalador entrega

Um único SmartAcesso-Setup-<versão>.exe instala, com checkboxes, as peças que aquela máquina precisa. O cliente não instala Java: cada serviço já leva a JRE correspondente.

Componente O que é Java / runtime Porta
Núcleo (sempre) Serviço Windows SmartAcesso Core — API local, sync, dispositivos JRE 21 64-bit (jlink) 8090
TopData (opcional) Serviço Windows SmartAcesso TopData — catraca / JNI Nitgen JRE 21 32-bit Liberica (jlink) 8080
Desktop (opcional) Aplicativo Electron SmartAcesso.exe Chromium embutido (não usa o Java da máquina) —

Tipos prontos no wizard:

  • Completa — núcleo + TopData + desktop
  • Operação — núcleo + desktop (estação sem catraca TopData)
  • Catraca — núcleo + TopData (máquina de equipamento, sem UI)
  • Personalizada — marca TopData e/ou desktop; o núcleo não pode ser desmarcado

Onde fica na máquina do cliente

C:\Program Files\SmartAcesso\
  core\          JAR + JRE 21 x64 + WinSW
  topdata\       JAR + JRE 21 x86 + WinSW + lib nativa
  desktop\       SmartAcesso.exe

C:\ProgramData\SmartAcesso\
  config\        application.properties (não é apagado na reinstalação)
  data\          Derby
  logs\
O TopData precisa de JVM 32-bit por causa das DLLs JNI (Nitgen / TopData). Por isso a build usa Liberica JDK 21 x86, o mesmo tipo de Java usado no desenvolvimento. O pom.xml do TopData pode continuar em Java 8 / Spring Boot 2.7: bytecode 8 roda no JVM 21.

2. Layout dos repositórios (obrigatório)

Os quatro repositórios precisam ser irmãos (mesmo diretório pai). O build.ps1 localiza os outros três a partir da pasta do instalador. 

C:\build\                                  ← qualquer pasta
  smartAcesso\
  smartAcesso-topData\                     ← precisa incluir lib\ (Topdata.jar, EasyInner.dll, NBioBSPJNI.jar)
  smartacesso-desktop-electron\
  smartacesso-installer\                   ← rode o build daqui
cd C:\build
git clone <url-do-smartAcesso>
git clone <url-do-smartAcesso-topData>
git clone <url-do-electron>
git clone <url-do-installer>

Os nomes das pastas têm que ser exatamente esses. Se o TopData vier sem a pasta lib\, o JAR não empacota as dependências de sistema.

3. Ferramentas na máquina de build

Windows 10 ou 11 64-bit. Essa máquina só gera o Setup; não precisa ter o produto instalado.

Ferramenta Para quê Observação
JDK 21 64-bit Compilar o núcleo e gerar a JRE x64 Oracle, Temurin, Microsoft, Liberica x64 — qualquer um com jlink
Liberica JDK 21 32-bit Compilar o TopData e gerar a JRE x86 BellSoft, pacote Standard JDK, Windows x86. Download: https://bell-sw.com/pages/downloads/
Node.js 20+ Empacotar o Electron node e npm no PATH
Git Clone dos repositórios —
Inno Setup 6 Compilar o .exe do wizard O script tenta instalar via winget se não achar o ISCC
Maven não precisa estar instalado. Os projetos Java usam o wrapper mvnw.cmd. Na primeira execução é obrigatório ter internet (Maven Central, npm, GitHub para baixar o WinSW).

4. Gerar o Setup.exe

PowerShell na pasta do instalador:

cd C:\build\smartacesso-installer
Set-ExecutionPolicy -Scope Process Bypass
.\build.ps1 -Version 1.0.0

O script procura os dois JDKs sozinho em C:\Program Files\... e C:\Program Files (x86)\... e imprime os caminhos encontrados. Se estiverem em outro lugar: 

$env:SMARTACESSO_JDK21     = "C:\caminho\jdk-21-x64"
$env:SMARTACESSO_JDK21_X86 = "C:\caminho\LibericaJDK-21-x86"
.\build.ps1 -Version 1.0.0

Arquivo gerado:

C:\build\smartacesso-installer\dist\SmartAcesso-Setup-1.0.0.exe

Esse é o instalador que vai para o cliente. As JREs já vão dentro dele.

O que o script faz, na ordem

  1. Compila o núcleo (smartacesso.jar) com JDK 21 64-bit e gera a JRE x64 com jlink.
  2. Compila o TopData (topdata.jar) com Liberica 21 32-bit e gera a JRE x86 com jlink.
  3. Copia lib\ do TopData para native\ no staging (exige EasyInner.dll).
  4. Empacota o Electron com electron-builder --win --dir.
  5. Baixa o WinSW (wrapper de serviço Windows), se ainda não estiver em tools\.
  6. Compila o Inno Setup e grava o Setup.exe em dist\.

Atalhos em rebuilds

ComandoQuando usar
.\build.ps1 Build completo (Java + Electron + Inno)
.\build.ps1 -SkipJava Só mudou o Desktop
.\build.ps1 -SkipJava -SkipElectron Só recompilar o wizard Inno a partir do staging já existente
.\build.ps1 -Version 1.1.0 Grava o número da versão no nome do Setup e no wizard

5. Instalação no cliente

Execute o Setup como administrador (já exige privilégio elevado).

  • Wizard em português, escolha do tipo (completa / operação / catraca / personalizada).
  • Opcional: atalho na área de trabalho e iniciar o Desktop com o Windows.
  • Os serviços são instalados e iniciados ao final.
  • A desinstalação não apaga C:\ProgramData\SmartAcesso\data nem os application.properties locais (Derby e config da estação).

Instalação silenciosa (TI)

SmartAcesso-Setup-1.0.0.exe /VERYSILENT /COMPONENTS="core,desktop"
SmartAcesso-Setup-1.0.0.exe /VERYSILENT /COMPONENTS="core,topdata,desktop"

6. Como testar

Não instale o Setup na mesma máquina em que os projetos sobem pelo IDE. As portas 8090 e 8080 vão conflitar. Use uma VM limpa (sem Java instalado de propósito).
  1. Instale o tipo Operação. Confira o serviço SmartAcesso Core e o atalho do Desktop.
  2. Rode o Setup de novo, marque TopData, e confira o serviço SmartAcesso TopData.
  3. Desinstale e confirme que C:\ProgramData\SmartAcesso\data permanece.
  4. Logs dos serviços: C:\ProgramData\SmartAcesso\logs\core e ...\logs\topdata.

Drivers USB de sistema (FTDI etc.) podem precisar do instalador do fabricante. O Setup empacota as DLLs de runtime TopData/Nitgen de smartAcesso-topData\lib\ em {app}\topdata\native (em especial EasyInner.dll). Sem elas o serviço TopData falha no start.

7. Problemas comuns na máquina de build

SintomaCausa típicaO que fazer
JDK 21 64-bit não encontrado Só existe Liberica 32-bit (JAVA_HOME x86) Instalar um JDK 21 x64 em Program Files, ou definir SMARTACESSO_JDK21
JDK 21 32-bit não encontrado Liberica x86 não instalada Instalar Liberica JDK 21 Windows x86, ou definir SMARTACESSO_JDK21_X86
Maven falha no TopData por systemPath Falta lib\Topdata.jar ou lib\EasyInner.dll Garantir que o clone do TopData inclui a pasta lib\ completa (ver lib\README.md)
electron-builder: ícone menor que 256×256 Usar o favicon 72×72 O projeto já usa src/assets/images/logos/icon.png (256×256)
Inno Setup não encontrado winget indisponível / política Instalar à mão em https://jrsoftware.org/isinfo.php e rerodar com -SkipJava -SkipElectron

8. O que ainda não entra nesta etapa

  • Atualização automática — combinado para depois. Enquanto isso, reinstalar o mesmo Setup atualiza os binários e preserva config/Derby.
  • Assinatura Authenticode — sem certificado o SmartScreen do Windows avisa no cliente.
  • Ícone definitivo — o icon.png 256×256 foi gerado a partir do favicon; pode ser trocado por um ícone de marca.
